# VANGUARD 2089 — Blackout Protocol

In-browser **Cyberpunk × Modern Warfare** 3D First-Person Shooter powered by a custom zero-dependency **WebGL2 PBR + PCF Shadows + HDR Bloom** engine and procedural **WebAudio** soundscape. Optimized for both **Desktop** (Mouse & Keyboard with Pointer Lock) and **Mobile** (Dual-Thumb Touch Controls, Auto-Sprint Joystick, Fire-to-Track, Magnetic Aim-Assist, Landscape & Portrait HUD).

## Modes
- **Campaign — Mission 01 (`Operation: Blackout Protocol`)**: 5-stage tactical mission through rain-drenched Neo-Kowloon Sector 04 culminating in the multi-phase **`ARES-IX "TITAN"`** boss mech fight and orbital extraction.
- **Endless Mode (`Protocol: Infinite Siege`)**: Escalating waves in **The Foundry** multi-tier arena with HVT boss waves every 5th wave and a live **Requisition Armory (`[B]`)**.
- **3D Armory & Codex**: Interactive 360° orbit/zoom turntable for all **6 Weapons**, **3 Playable Operators**, and **7 Enemy Classes**.

## Build & Run Locally
```bash
node build.mjs
node server.mjs
```
Then open `http://localhost:8089` (or open `index.html` directly in any modern WebGL2 browser).
